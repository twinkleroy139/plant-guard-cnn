# Plant Guard CNN 🌿🤖

A Convolutional Neural Network (CNN) application designed to classify plant leaves as healthy or diseased, deployed as an interactive web app using Streamlit and PyTorch.

You can access the live web application here:
[👉 Click here to view Plant Guard Live](https://plant-guard-cnn.onrender.com)

## 🛠️ Tech Stack
* **Deep Learning:** PyTorch, Torchvision
* **Frontend/UI:** Streamlit, Custom CSS
* **Deployment:** Render Cloud Platform
